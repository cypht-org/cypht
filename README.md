# Cypht

All your email, from all your accounts, in one place.

Cypht combines your accounts into one view. It does not replace them.
It is also a standard email client: browse and manage your folders, read
and send messages. And it works as a news reader too.

![Cypht inbox view](https://raw.githubusercontent.com/cypht-org/cypht-website/master/static/img/home/message_list_light.webp)

Website: [cypht.org](https://cypht.org)

## Supported protocols

- IMAP and SMTP
- [JMAP](https://jmap.io) (added in [#180](https://github.com/cypht-org/cypht/issues/180))
- Microsoft Exchange (EWS), via [php-ews](https://github.com/Garethp/php-ews) (added in [#247](https://github.com/cypht-org/cypht/issues/247))

## Built from modules

Cypht is built entirely of module sets (our name for plugins). Every feature
is a module, so you can add or customize features without changing the core
code. See the [module list](https://cypht.org/modules).
