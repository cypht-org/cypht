## IMAP

This module set provides email account integration and message management for Cypht. Despite its name, it supports multiple mail server protocols including IMAP, JMAP, and Exchange Web Services (EWS), making it compatible with a wide range of email providers and enterprise mail systems.

The imap module is fundamental to Cypht's email functionality and is required for webmail usage. It integrates with other modules to provide email composition, listing, search, and other advanced features. If you are using Cypht as a webmail program, this module must be enabled.
