## Advanced Search

This module provides more sophisticated search capabilities, allowing users to perform complex searches that they could not otherwise achieve with the basic built-in search. Some notable search criteria and features include:

* Targeted source search — choose which sources you want to search
* Negative search terms — find items that exclude a given term
* Time-range-specific searches
* And many more settings and fields for a flexible and dynamic search experience

The Advanced Search module requires the imap module to process requests. Therefore, the imap module should be enabled before enabling this module.
